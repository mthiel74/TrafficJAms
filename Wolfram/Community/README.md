# Wolfram Community post

This directory bundles everything needed to post the project as a
**code-first interactive notebook** to
[community.wolfram.com](https://community.wolfram.com/).

## What to upload

Upload **all of these files to the same Community post** (they must
end up in the same directory after the reader downloads them):

### The notebook (main content)

- `trafficjams.nb`

### Model packages (attachments)

| File | Purpose |
|---|---|
| `IDM.wl` | Intelligent Driver Model |
| `Bando.wl` | Optimal Velocity Model |
| `LWR.wl` | Lighthill–Whitham–Richards PDE |
| `PayneWhitham.wl` | Payne–Whitham second-order PDE |
| `NagelSchreckenberg.wl` | Stochastic CA |

| `CoreAnimations.wl` | Ring / corridor frame renderers |

Total: ≈ 100 KB for all 13 `.wl` files + 40 KB for the notebook.

## How the notebook works

The first input cell does:

```wolfram
SetDirectory[NotebookDirectory[]];
Get["IDM.wl"]; Get["Bando.wl"]; ... Get["CoreAnimations.wl"];
```

so all subsequent `Simulate*[]`, `Plot*[]`, and `*Frame[]` calls
resolve against the attached packages. Every figure and animation in
the notebook is regenerated by running the code in its section —
there are no pre-embedded images, so the file stays tiny (≈ 40 KB).

## Skipping the OSM-based Aberdeen simulations

The city-centre and full-city v2 multi-agent simulations live in
the GitHub repo (`AberdeenCityNetwork.wl`, `AberdeenFullCity.wl`)
but are **omitted from this bundle** because they need OSM JSON
caches (1.3 MB / 8.8 MB) which are awkward to attach to a Community
post. The relevant section in the notebook links to the repo for
readers who want to run them locally.

## Rebuilding

```bash
wolframscript -file build_notebook.wls
```

regenerates `trafficjams.nb` from the source in `build_notebook.wls`.
